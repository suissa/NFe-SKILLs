# NFC-e — Nota Fiscal de Consumidor Eletrônica (modelo 65)

A NFC-e registra operações de venda ao consumidor final, especialmente no varejo, conforme as regras estaduais aplicáveis. É um documento fiscal eletrônico em XML, assinado digitalmente e autorizado pela administração tributária competente. O DANFE NFC-e/QR Code é uma representação auxiliar e não substitui o XML autorizado.

## Diferença para NF-e

A NFC-e (modelo 65) é voltada ao varejo ao consumidor final e possui regras próprias de credenciamento, identificação do consumidor, QR Code, contingência e autorização. Não escolha o modelo apenas pelo canal de venda: confirme a legislação e as condições de uso da UF.
