# CT-e — Conhecimento de Transporte Eletrônico (modelo 57)

O CT-e documenta prestações de serviço de transporte de cargas nos casos previstos na legislação. É um documento fiscal eletrônico estruturado em XML, assinado digitalmente e autorizado pelo sistema tributário competente. O DACTE é a representação auxiliar do CT-e, não substitui o XML autorizado.

O tipo de documento e o fluxo devem ser confirmados conforme a operação de transporte, participantes, modal e legislação aplicável.
